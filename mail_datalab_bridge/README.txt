ARM (Windows + Outlook)
=======================

1. Установите зависимости:
   python -m pip install -r requirements.txt
2. Заполните TECH_MAIL_FOLDER, TECH_MAIL_SMTP, RELAY_MAIL_SMTP и кодовые
   темы в config.py.
3. Запустите Outlook, затем:
   python main.py

ARM выполняет всю внешнюю цепочку:

  пользователь -> технический ящик -> JSON в relay-ящик -> ответный JSON
  -> технический ящик -> пользователь

Вопросы внутри одного письма не разбиваются. Тело очищается только от цитат
и типовой подписи и целиком передаётся обработчику VARM. Итоговое письмо
содержит исходный вопрос и ответ.

Состояние атомарно сохраняется в state.json. Поэтому после перезапуска уже
учтённое письмо не становится новым. При сбое во время Send() процесс ждёт
SEND_RECOVERY_SECONDS и проверяет папку «Отправленные» перед повтором.
Старая версия DataLab имела другой формат state.json: при первом переходе
переименуйте её файл состояния, повторно использовать его нельзя.

Только после появления итогового ответа в «Отправленных» сообщения цепочки
перемещаются в «Удалённые»: исходное письмо, ответный служебный JSON и копия
запроса из «Отправленных». Завершённая запись остаётся в state.json для
защиты от повторной обработки.

Лог ARM пишется в mail_agent.log. Запускайте только один экземпляр процесса.
На VARM используется существующая инициализация EmailConfig и существующий
внешний цикл с process_incoming_emails(answer_function) из
../my_server_halper/mails_handler.py.
